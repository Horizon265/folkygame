# folkygame
folkygame is a python based game made by using the principles of menu driven programs 
It functions like a linguistic horror quiz where it tests the linguistic knowledge of a person while also catering to the horror vibe of the spooktober season.
while I was at boba bash delhi this game came in my mind as i was recently practicing menu driven programs in python.
To summarise it all folkygame is a python game operating on the principles of a menu driven program it is a linguistic quiz based game which caters to the halloween spirit while also checking the linguistic knowledge of a person made by me at boba bash delhi for submission in the 3 a.m. hackclub program.
